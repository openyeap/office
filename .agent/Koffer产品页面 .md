# 一、页面全局通用规则
## 1. 布局规范
- 整体：**通栏布局 + 区块分割**，区块之间留白充足，上下间距统一
- 内容宽度：PC 最大内容宽度 1200px，居中展示；移动端全屏自适应，内边距左右 16px
- 字体：系统无衬线字体，正文 14px，小标题 18px，大标题 24~32px，重点文案加粗
- 分割：每个功能区块使用浅灰色分割线/留白区隔开，视觉层次清晰

## 2. 交互通用规则
1. 所有按钮：hover 浅变色，点击无特殊弹窗（外链/内部跳转）
2. 导航栏：顶部全局导航固定吸顶
3. 图片/截图：统一圆角 8px，加轻微阴影
4. 锚点：页面右侧固定悬浮**目录锚点导航**（PC端），点击滚动到对应区块
5. 跳转按钮：统一文案「了解更多」「立即体验」「查看文档」

## 3. 页面必备固定元素
- 顶部：网站全局导航栏（首页 / 产品中心 / 标杆案例 / 文档教程 / 体验入口 / 关于我们）
- 底部：全站统一页脚（版权、ICP备案号、隐私政策、用户协议、联系邮箱）
